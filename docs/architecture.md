# Architecture — bebebe-game v2 (3D)

One `index.html` (+ PWA files, see below): a small non-module script (offline hint) and one `<script type="module">` that imports Three.js r187 from jsDelivr. Two stacked canvases inside `#wrap`: `#gl` (WebGL, Three.js) below, `#game` (2D, UI and input) on top.

## Layers (keep them apart)
1. **Logic** — world, level generator (pure: no Three.js, no place), pathfinding, rules, bots, the Big One, items, progress. Works in "logic pixels": 960×640, `CELL = 32` (1 cell = 1 unit in 3D). Knows nothing about Three.js.
2. **3D** — builds meshes from the world (`buildMap3D`, `buildCharacters`) and copies state into them every frame (`syncScene` → `syncLittle`, `syncBig`, `syncItems`, `syncStars`, `syncKisses`, `updateCone`). Only reads game state.
3. **2D UI** — menus, HUD, name tags, timers, shop, skins screen; positions of world things via `toScreen(x, y, heightPx)`. Buttons are registered each frame in `buttons[]` and hit-tested on `pointerdown`.

## Level types and the generator (SPEC-002)
- **Type and tier**: `levelType(lv)` = `"classic"` for level 1, else `CFG.TYPE_ORDER[(lv - 2) % 6]` (`meadow`, `maze`, `village`, `river`, `rooms`, `arena`); `levelTier(lv)` = `Math.floor((lv - 2) / 6)` (0 for level 1). Each tier removes one bush (`bushCount`), never below `CFG.BUSH_MIN[type]`.
- **`generateLevel(lv, attempt)`** (pure, place-free, seeded only by `mulberry32(lv * 7919 + attempt * 104729 + 13)`): builds the layout context `lc` (`lv, attempt, type, tier, rng, ri, items, occ, reserve, isFree, hWall, vWall, place(n, make, w, h, m, ok)`, `small`, `bigPt`, `doors`, `homes`, `meta`) → **`placeHomes(lc, variant)`** (Little Ones' house 7×6 top-left with `safe`, beds and spawns; the Big One's 6×6 house through `bigHouse()` bottom-left `"side"` or bottom-right `"diagonal"`; `CFG.DOOR_APRON` cells reserved in front of every door; `variant` = `"side"` for classic, `CFG.LAYOUT[type].homes` if set, else the seed) → **`LAYOUTS[type](lc)`** → mirror `fx`/`fy` (not on level 1; mirrors items, danger `exits`, `meta.areas` and the doors) → flowers. Returns `{ type, items, small, big, flowers, doors: { small, big }, meta }`; `doors` = door openings `{ x, y, w, h, dx, dy }` (outward direction) for the fairness rules; `meta` = layout facts (`deadEndsBefore/After` for the maze, `areas` — plazas, bridges, rooms + doors, arena block/ring/gaps — for tests, `bad` = the layout could not be built, `vertical` for the river).
- **Layouts** (all sizes in `CFG.LAYOUT[type]`): `classicLayout` = the old body, byte-for-byte (fixture `tests/fixtures/level1.json`); `meadowLayout` (ponds, trees, rocks, bushes); `mazeLayout` (3-cell modules: Kruskal perfect maze, home areas and 5×5 plazas opened, braided to ≤ `CFG.MAZE_DEAD_ENDS`, walls as `maze` cells); `villageLayout` (`floor` `square` + fountain `pond`, `cottage` blocks with `street` margin, bushes next to cottages); `riverLayout` (`water` pieces between the houses, bends, `floor` `bridge` with `across: "x"|"y"`, bushes split between banks); `roomsLayout` (diagonal only: two wings with BSP rooms, `build` walls, `tile` floor, outside doors into both yards); `arenaLayout` (diagonal only: `arena` block and ring with gaps, optional half-ring). `emitWalls(items, occ, wall, kind)` turns a wall-cell grid into wall rectangles.
- **Item kinds and flags** (`applyWorld` → `obstacles`): `wall` kinds `home`/`bighome`/`build`/**`maze`**/**`arena`** (and `hedge` from the fallback) — move + sight; **`cottage`** — rect, move + sight; **`water`** — rect, move only (sight passes); `pond` — move only, `fountain: true` for the village fountain; `tree`/`rock` — circles, both. `floor` kinds `wood`/`tile`/**`bridge`** (`across` kept)/**`square`** are walkable ground only. Bridges are gaps between water pieces, so they are free cells.
- **`buildGrids()`** rasterizes: each obstacle marks only the fine/coarse cells of its own bounding box (same rules as `covers()`), because a level may be built up to `CFG.LEVEL_ATTEMPTS` times; then `moveGridBig`/`blockedBig` add the safe zone.
- **`validateLevel(gen, type)`** (on the applied world) → `{ ok, fails, seen, freeRatio, bigReachAll, smallReachAll, housePath, doorClear, deadEnds: { count, longest, before }, bushes }`. Rules: `smallReach` (`connectivity()`), `bigReach` (`floodCells` on `blockedBig` from his spawn), `housePath` (A* on `blockedBig`, √2 diagonal, shortest big-door → cell-in-front-of-small-door pair, in `CFG.HOUSE_PATH`; skipped for `classic`), `free` (`CFG.FREE_MIN[type]`, outside both houses), `doors` (`CFG.DOOR_APRON` rows in front of every door free on both grids), `deadEnds` (`deadEndScan`: 2×2 free windows of `blockedBig` as nodes, leaves peeled; maze: count outside houses and aprons ≤ `floor(before × MAZE_DEAD_ENDS)`, others: `longest ≤ CFG.DEAD_END_MAX`), `bushes` (`CFG.BUSH_MIN`), plus `layout:<meta.bad>`.
- **`buildLevel(lv)`**: attempts 0…`LEVEL_ATTEMPTS - 1`, first `ok` wins. Fallback: rebuild the attempt with the lowest `failScore` (fail count, +100 if a reach rule failed), fill with `hedge` every free cell the Little Ones can't reach or (outside their house) the Big One can't reach, `console.warn`. Sets `reachable`; returns the report without `seen`/`ok`, plus `tier`, `attempt`, `attempts`, `fallback`, `rejects`, `ms`.
- **`loadLevel(lv)`** (from `resetWorld`): `levelCache` (level → accepted attempt) rebuilds that attempt directly and re-validates it; a cached attempt that no longer passes (e.g. `CFG` changed) is dropped and the level is built from attempt 0. Fallback results are not cached. Sets **`levelInfo`** `{ lv, type, attempt, fallback, cached, ms }`. `clearLevelCache()` empties the cache.
- **`levelReport(lv)`** (tests): saves the world (`keep` = `obstacles, bushes, floors, decor, trees, flowers, safeZone, dangerZone, spawns, reachable` + copies of the five grids), runs `buildLevel`, restores everything in `finally`. The comment above `applyWorld` says it: new world state → add it to `keep` and to `__bb.worldState`.
- **Bots on new layouts**: `fleePoint` only picks `reachable` cells and falls back to `freePointNear`; `lurkPoint` snaps to `freePointNear(p)` (nearest free reachable cell via `freeCellNear`), so targets are never inside walls or across water.
- **3D** (`buildMap3D`): `cottage` → `makeCottage` (body, pitched roof along the long side, snow on winter roofs, door, windows); `water` → `makeWaterFor` (flat, no rim, so pieces join into one river; waves except winter) + `riverBanks` (one `InstancedMesh` of edge strips on water sides not next to water, a bridge or the map edge; stone edge in the schoolyard); fountain `pond` → `makeFountain` (bowl, water, column, bobbing drop in `waves`, `userData.baseY`); `maze` walls → boxes in `THEMES[place].maze` colours + `mazeDeco` (`InstancedMesh`: bumps, posts, snowballs, locker seams); `arena` walls via `walls.arena`. Maze walls keep `WALL_H` 0.85 (characters stay visible). `paintGround` draws `bridge` planks (across the crossing) and `square` cobbles. `tag(mesh, piece)` sets `userData.piece` for `__bb.mapPieces()`; `disposeTree` also disposes `InstancedMesh` buffers.
- **Theme keys** (`THEMES[place]`): `walls.arena` `[wall, top]`; `maze` `{ wall, cap, deco: "bumps"|"posts"|"snow"|"seams", decoC }`; `cottage` `{ wall, roof, door, window, snow? }`; `water` `{ c, edge, stone?, waves, wave }`; `bridge` `[plank, gap]`; `square` `[base, stone]`; `fountain` (bowl colour).
- **Banner and menu label**: `startGame` → `showBanner()` sets `banner = { text: levelIntro(level, types[type]), t }` unless the last banner was under `CFG.BANNER_REPEAT` s ago; `updateFx` advances `banner.t` and clears it at `CFG.BANNER_TIME`; `bannerAlpha()` fades over `CFG.BANNER_FADE`; `drawBanner()` (only in `play`) draws the plate under the top bar, adds no buttons. The menu draws `types[levelType(level)]` between the rules and the level selector and stores its box in `typeLabel` `{ text, x, y, w, h, size, rulesBottom }`.
- **Test fixtures**: `tests/fixtures/level1.json` (items and spawns of `generateLevel(1, 0)`; level 1 must match exactly), `tests/fixtures/levels-2-61.json` (per level: type, accepted attempt, FNV hash of the generated JSON — regenerate only on purpose, saying why in the commit). Tests that change `__bb.CFG` restore it and call `__bb.clearLevelCache()`.

## The Big One's house (SPEC-003)
- **`bigHouse(items, x0, y0, doors)`** (generator section) emits everything of the 6×6 house: `bighome` walls with 2-cell doors (`doors: [{ side: "top"|"bottom"|"left"|"right", at }]`), the dark floor, the bed, and the danger item `{ t: "danger", x, y, w, h, exits }` = the floor; `exits` are 2-cell spots `CFG.DANGER_EXIT` cells outside each door. The mirror step in `generateLevel` mirrors `exits` too. Level 1: doors top and right, same layout as before. `placeHomes` (SPEC-002) builds the Big One's house through `bigHouse()` on every level type, so every type has the danger zone.
- `applyWorld` turns the item into **`dangerZone`** `{ x, y, w, h, exits: [{x, y}] }` (pixels; exits are the spot centres); `inDanger(p)` / `inDangerXY(x, y)` test it. `reachable` (from `connectivity()` in `loadLevel`) marks the cells the Little Ones can reach from their house.
- `updateDanger(dt)`: a Little One in state `ok` inside the zone gets `dangerT += dt` (paused while `hugAnim` > 0, reset to 0 outside or in any other state); at `CFG.DANGER_TIME` → `throwOut(l)`: placed at `nearestExit(l)` (or `freeCellNear` it: not blocked, reachable, not in the zone), `dizzy = CFG.DIZZY_TIME`, pop text `thrownOut`, `SFX.thrown`.
- Bots: `steerTo` adds `CFG.BOT_DANGER_COST` per danger cell to their A* cost (not for the Big One); `fleePoint` and `lurkPoint` never pick a point in the zone; a bot with `dangerT > CFG.BOT_DANGER_LEAVE` gets task `leave` and walks to `nearestExit`.

## Bonus stars (SPEC-003)
- `bonusStars` (`{ id, x, y, t, life }`), separate from `items`; `starCd` counts down `CFG.STAR_EVERY`, at most `CFG.STAR_MAX`, each lives `CFG.STAR_LIFE` and blinks for the last `CFG.STAR_BLINK` (in `syncStars`).
- `starSpotOk(cx, cy)`: not blocked, `reachable`, not in `safeZone`/`dangerZone` nor within `CFG.STAR_HOUSE_MARGIN` cells of the Big One's floor, at least `CFG.STAR_MIN_FROM_HOME` cells (straight line) from the safe house walls, no item or star on the cell. `spawnStar(x?, y?)` picks a random good cell (or the given point, for tests).
- `updateStars`: a `player` with `canAct` within `r + CFG.STAR_PICK` takes it: `stats.starCoins` and `progress.coins` += `CFG.STAR_COINS` at once (saved), pop text, burst, `SFX.star`. `giveReward` reports them as `lastReward.starCoins` (and inside `lastReward.coins`), on top of the `COINS_MIN_WIN` floor; the win and lose screens show them as a separate line.

## Names (SPEC-003)
- Slots `p1`, `p2`, `big`, `bot1`..`bot4`. `namesTyped` holds only what a kid typed (`""` = language default); `nameFor(slot)` = typed or `defaultName(slot)` (`player1`/`player2`, `defaultBig`, `defaultBots[i]` of the current language). `cleanName`: control characters removed, trimmed, at most `CFG.NAME_MAX` code points. `nameOf(l)` maps a character to its slot (bots by `botIndex`). Names are drawn only with `fillText`.
- **Name input overlay**: `nameLabel(rect, slot, color)` draws a label button with ✏️ and registers it with `onUp: true`; such buttons fire on **`pointerup`** of the same pointer (`pendingUp`), because iOS Safari opens the keyboard only for a focus inside a pointerup/click. `openNameInput(rect, slot)` puts an HTML `<input class="name-input">` exactly over the rect (`placeNameInput`, from `CSS_W / W`, font ≥ 16 px, `enterkeyhint="done"`, `autocapitalize="words"`); Enter, blur or a tap on the canvas saves, Escape cancels; saving an unchanged name keeps the default. While `nameInput` is open, `keydown` and gamepad buttons are ignored; `drawUI` closes it when the mode is no longer `skins`/`names`.
- In play: `drawMarkers` draws names above heads (40 % alpha in a bush) and the Big One's name above him; `drawHUD` starts the hearts bar with his name (`labelFit` shrinks or cuts long names; hearts get denser above 8).

## Air kisses (SPEC-004)
- **Shop and stock**: `KISSES = { price, pack }`; `buyKisses()` takes `KISSES.price` coins and adds `KISSES.pack` to `progress.inv.kisses` (one pool for both players); not enough coins → `SFX.out`. The shop draws three cards from one list (mittens, mega, kisses; button ids `buy:<kind>`), card text by `fitText`/`wrapText`; texts `kisses`, `kissDesc`, `kissPack(n)`, `kissHave(n)` (ru uses `ruPlural`), pop texts `kissHit`, `noKissHome`, `blush`.
- **Throw**: `throwKiss(pi)` works only in `play`, without `pendingWin`, for a `player` with `canAct` and `inv.kisses > 0`. In `safeZone` → pop text `noKissHome`, nothing spent. Then `kissCd` must be 0: one kiss is spent (saved), `l.kissCd = CFG.KISS_COOLDOWN` (counted down in `update`), and a kiss `{ id, owner, x, y, dx, dy, travel }` starts at the player's front along `l.dir`. Inputs: `onKey` → `kissKeyPlayer(code)` (one player: `KeyE`/`Space` → 0; two players: `KeyE` → 0, `Enter`/`NumpadEnter` → 1); gamepad button `CFG.PAD_KISS` (2 = X / □) in `onPadButton(b, pad)` (with two players pad i throws for player i); touch `kissButton(pi)`.
- **Flight**: `updateKisses(dt)` (called in `update` after `updateHugAnim`) moves each kiss in steps of `CFG.KISS_STEP` at `CFG.KISS_SPEED`, up to `CFG.KISS_RANGE`. Each step checks, in this order: `seeSolidAt` (the sight grid: every wall kind, trees, rocks, cottages, the map edge → puff, done; ponds, water, bushes pass); the hit `dist < big.r + CFG.KISS_HIT_PAD` **and** `los(kiss, big, seeSolidAt)` (never through a wall); the end of the range. Sight-blocking walls added by SPEC-002 stop kisses automatically through the same grid.
- **Hit**: `kissHit(k)` always bursts hearts; no damage while `big.stun`, `big.hugCd` (the 0.3 s after the shock) or `big.blush` > 0. Otherwise `big.hp -= CFG.KISS_DAMAGE` (floor 0), `big.blush = CFG.KISS_BLUSH`, `big.blushBy = k.owner`, `pushCd` cleared, pop texts `kissHit` + `blush`, `SFX.mwah`; `hp` 0 → `winSoon()` (the same path as the last hug: `pendingWin`, rewards, stars).
- **Touch button**: `kissBtnRect(pi)` (size `CFG.KISS_BTN`; bottom right, or bottom left for P1 with two players). `drawHUD` calls `kissButton(pi)` only on touch, in `play`, with `inv.kisses > 0`; it pushes `{ id: "kiss:<pi>" }` into `buttons[]`. `pointerdown` hit-tests `buttons[]` before it starts a stick, so a touch on the button never starts a joystick. Grey when not `canAct`, in the house or during `kissCd` (cooldown arc). Without touch the HUD shows `💋 ×N` next to the mittens.
- **3D**: `syncKisses` keeps one mesh per kiss in `kissGroup` (`kissMeshes` by id): an extruded pink heart at `KISS_Y` (chest height) with a sparkle trail; `rebuild3D` clears them. The Big One's blush (`syncBig`): `headMat.emissive` red, `cheeks` visible, head tilted up, hands together; 💗 label in `drawMarkers`; pale cone in `updateCone`.

## Half hearts (SPEC-004)
- `big.hp` holds 0.5 steps (hug power is whole, kiss damage 0.5, both exact in floating point).
- `heartFill(i, hp)` = `clamp(hp - i, 0, 1)` (1 full, 0.5 half, 0 empty); `drawHpHeart(x, y, s, f)` draws a half as left red / right grey. `drawHUD` uses both for the hearts bar.
- `bigBoost()` = level boost + `Math.floor(maxHp - hp) * CFG.BIG_SPEED_PER_HIT` (only whole hearts lost speed him up); used by `updateBig`.
- `fmtHearts(n)`: 2.5 → `2½`, 0.5 → `½`, 0 → `0`; the lose screen passes it to `loseSub`.

## States
- **Game `mode`**: `menu` · `skins` · `names` (bot names, opened by "👥 Friends" on the skins screen) · `shop` · `play` · `pause` · `win` (· `lose` — screen still exists but is not reached since "no game over").
- **Little One `state`**: `ok` → `down` (pushed; `downTimer` = `CFG.DOWN_TIME`) → rescued (`rescue` reaches `CFG.RESCUE_TIME` while a helper stands next to him, drains at `CFG.RESCUE_DRAIN` otherwise, reset to 0 when the helper is pushed) → `ok` (`invuln`) | not rescued → `home` (limps to `restSpot` = its spawn in the house) → `rest` (`restTimer` = `CFG.REST_TIME`) → `ok`. Extra: `hugAnim` > 0 while riding the Big One's shoulders; `fx.boots/cloak/shield` timers; `dangerT` (seconds in the Big One's house); `dizzy` (after being thrown out: can't move or hug, the Big One ignores him); `botWait` (set on a fall from `CFG.BOT_RESCUE_DELAY`; bots ignore the downed one until it is 0). **`canAct(l)`** = `ok`, no `hugAnim`, no `dizzy` — used for moving, hugging, contacts, picking stars, throwing kisses. `kissCd` (SPEC-004): seconds until this player can throw the next air kiss.
- **Big One**: `state` `look` / `patrol` / `chase` / `search`; overlays `stun` (after a hug, can't move/push, no new hug), `slip` (banana: lying, can be hugged from any side), `pushCd` (stands after a push), `noPush` (rest after a push: sees nobody), `blush` / `blushBy` (SPEC-004, after an air kiss: seconds left and the thrower's player index). While `blush` > 0 he doesn't move, turn or push, bots don't flee and the cone is pale, but he **can be hugged** (`hug` sets `blush = 0`, then the usual `stun`). `blush` also counts down while he lies after a banana (`slip`). When it reaches 0 with no `slip`/`stun`: `state = "chase"`, `lastSeen` = the thrower's position, `dir` turned to the thrower at once; if it ends during `slip`, the slip end sends him to `look` as usual.
- **Bots**: `task` `rescue` / `flee` / `attack` / `lurk` / `leave` (walking out of the Big One's house); one attacker at a time (`attackToken`, `botAttackCd`).

## PWA (SPEC-001)
- **Site files** (all that GitHub Pages publishes): `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` (`icon.svg` source → PNGs by `scripts/make-icons.js` / `npm run icons`), `v1-2d/`. Workflow `.github/workflows/pages.yml`: job `test` (whole Playwright suite) → job `deploy`.
- **`index.html` head**: `<link rel="manifest">`, `apple-touch-icon`, `apple-mobile-web-app-*` metas, `viewport-fit=cover`. `body` is padded with `env(safe-area-inset-*)`; `playArea()` (screen section) returns the body's box minus that padding and `fit()` sizes the canvases from it (on `resize` and, a frame later, on `orientationchange`).
- **`isStandalone()`** (screen section, computed once into `STANDALONE`): `navigator.standalone`, `(display-mode: standalone)` or `?standalone=1` (tests). Hides the HUD fullscreen button (`drawHUD`) and the install hint. `isIOS` + `showInstallHint()` → one menu line `I18N.installHint` under the controls text (`drawOverlay`, menu).
- **`sw.js`**: `SW_VERSION` names the cache. `install` precaches `./`, `./index.html`, the manifest, the icons and jsDelivr `three.module.js` + `three.core.js` (CORS), then `skipWaiting()`. `activate` deletes other `bebebe-*` caches only (all Pages projects of the account share the origin), `clients.claim()`. Fetch: navigations and `index.html` network-first — the cache answers when the network fails, returns a non-OK status, or takes longer than `NET_TIMEOUT_MS` (root fallback `./`); three.js and `icons/` cache-first; everything else network-first. Bump `SW_VERSION` when the precache list (e.g. the three.js version), an icon or a strategy changes.
- **Registration guard** (`registerServiceWorker()`, main loop section, after `__bbReady`): only on `http:`/`https:` with `navigator.serviceWorker`, inside `try/catch`, rejected promise swallowed — nothing happens on `file://` or in the claude.ai page.
- On iOS the home-screen app has its own `localStorage`, separate from Safari.

## Save data (localStorage)
- `bebebe-progress`: `{ unlocked, stars: {level: 1..3}, coins, inv: {mittens, mega, kisses}, equip: [p1, p2] }`. Defaults come from `freshProgress()` (also used by `resetProgress`); loading merges with them, and `inv.kisses` is forced to a whole number ≥ 0 (old saves without it, or broken values → 0).
- `bebebe-outfits`: `{ p1: {hair, hat, jacket, pants}, p2: {...}, big }`. `bebebe-place`: `auto|park|beach|winter|school`. `bebebe-lang`: `en|es|ru`.
- `bebebe-names` (SPEC-003): `{ p1, p2, big, bots: [b1, b2, b3, b4] }` — only typed names, `""` = language default; every field cleaned on load, missing or broken data → defaults.
